# 001 可视化固定资产管理台账

## 打开方式

1. 在项目根目录运行 `npm run dev`。
2. 使用最新版 Windows Chrome 或 Edge 打开 `http://localhost:3000/tools/001-fixed-asset-ledger`。
3. 在平台主页点击“本地工作区”，选择一次共享根目录并允许读写；首次打开本模块时会在其中创建“001 可视化固定资产管理台账”文件夹。

本模块不会上传 GLB、项目数据、台账或封面。浏览器私有存储只保存目录句柄和非权威项目摘要，用户选择的文件夹是项目数据的唯一主存储。

## 首次建立项目

1. 在项目中心点击“新建项目”，填写名称并选择自包含的 `.glb` 文件。
2. 在首次初始化页勾选资产对象；未勾选对象作为场景对象保留。
3. 可把类别批量应用到已选对象，也可从 Excel 粘贴一整列编号。
4. 补齐编号、名称、类别和颜色后点击“完成初始化”。相同编号会合并为同一项多节点资产。

## 日常使用

- 左侧三维区首次使用高位俯视角，支持旋转、平移、缩放、复位和聚焦；选中资产时只平移视角，不改变当前观察距离。资产标签固定在模型中心，并可用标签开关统一显示或隐藏。
- 模型和台账之间可双向悬停、选中和定位；按 `Esc` 清除选中，`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。
- “类别”管理默认色和批量改类；“字段”管理文本、数字、日期、单选和是/否字段。
- 颜色入口使用模块内常驻面板，可连续点击常用颜色或调整 RGB 通道；点击面板外、按 `Esc` 或关闭按钮才会收起。
- 修改会防抖自动保存。保存失败时可重新授权、重试或导出应急 JSON 副本。
- 项目先进入回收站，只有再次输入完整项目名后才会永久删除目录。

## 导出和迁移

- “XLSX”可导出全部资产或当前筛选结果，同时刷新项目目录内的 `ledger.xlsx`。
- “设为封面”保存当前相机和 `preview.png`。
- “项目 ZIP”生成未加密标准包；导入时先验证版本、路径、大小、压缩比、清单、项目数据和 GLB 节点映射，再登记项目。
- 同项目编号冲突时默认另存为副本；显式覆盖会先完整写入并校验新目录，再替换旧项目记录。

## 磁盘格式

当前工作区格式、项目格式和项目包格式均为 V1。目录只保存相对路径：

```text
工作区/
├─ workspace.json
└─ projects/
   └─ 安全化项目名-短编号/
      ├─ manifest.json
      ├─ project.json
      ├─ project.recovery.json
      ├─ model.glb
      ├─ preview.png
      └─ ledger.xlsx
```

`project.json` 是唯一业务主数据；`project.recovery.json` 用于写入中断恢复。重命名项目不会改动稳定磁盘目录名。

## 验证记录（2026-08-14）

- 测试机：Windows 10.0.26200.9168、AMD Ryzen 9 5900HX、31.4 GB 内存。
- 浏览器：Chrome 151.0.7922.108、Edge 151.0.4129.78。
- 脱敏模型：`3 cubes.glb`，4,540 字节，识别 3 个顶层候选对象。
- 真实浏览器自动流程已覆盖：本地写入、三维加载、初始化、台账生成、ZIP 导出、项目永久删除后向空工作区重新导入。
- 单独运行时从点击“创建并导入”到初始化三维场景可见约 0.5–0.8 秒；并行全套回归时约 1.6 秒。
- 浏览器测试记录的 JS 堆从约 17–21 MB 增至约 39–46 MB。无外部请求或项目数据写入请求。
- 500 MB 流式复制路径使用 1 MB 分块的 500 次写入自动验证，不会组装完整内存副本。

## 已知边界

- 所给真实模型只有 4.5 KB，不能代表 500 MB 模型。500 MB 真实模型的加载耗时、峰值内存和可见帧率仍取决于几何、纹理、压缩扩展及用户硬件，必须在取得代表性大模型后另行实测。
- 自动化使用无界面的系统浏览器；其 `requestAnimationFrame` 回调频率不等同于显示器上的实际帧率，因此不作为交互 FPS 结论。
- 原生目录授权弹窗无法由自动化代替用户确认。端到端测试使用浏览器原生临时文件系统验证同一套读写接口；正式使用始终由用户手势选择真实本地文件夹。
- 仅支持最新版 Windows Chrome/Edge 和安全上下文（localhost 或 HTTPS）；不支持 `.gltf` 外部资源项目、移动端、云同步或 XLSX 回导。
